============================================================
META / SEO + AEO PROMPT
============================================================

Covers: Meta Title, Meta Description, Open Graph, Twitter Card, canonical
URL, AEO (Answer Engine Optimisation), and AI Overview Snippet optimisation.

BRAND DETECTION: Follow _Brand_Detection_Rules.txt before generating.

Once the brand is confirmed, use the template below.

------------------------------------------------------------
SECTION 1 - META TAGS (Traditional SEO)
------------------------------------------------------------

Create SEO meta tags for [BRAND NAME], [BRAND DESCRIPTION], for the blog post titled "[BLOG TITLE]" at [URL]. Generate a meta title and meta description. The meta title should be under 60 characters, include the primary keyword, and be compelling enough to earn a click. The meta description should be 140-160 characters, summarise the page value clearly, and include a subtle call to action. Do not use em dashes. Avoid passive voice.

Blog URL: [INSERT BLOG URL]
Primary Keyword (if known): [INSERT KEYWORD OR LEAVE BLANK]

------------------------------------------------------------
SECTION 2 - OPEN GRAPH + TWITTER CARD + CANONICAL (Social + Dedup)
------------------------------------------------------------

Meta tags do not cover social preview cards or duplicate-content deduplication - both are separate protocols the LLM MUST also emit, or the page will look broken on Facebook/LinkedIn/Slack and get merged with duplicates in Google's index. For the same blog post, generate:

1. OPEN GRAPH TAGS (Facebook, LinkedIn, Slack, WhatsApp preview cards):
   - og:title (may equal meta title; may also be a longer, sharier variant up to 95 chars)
   - og:description (up to 200 chars; punchier than the meta description)
   - og:type ("article" for blog posts)
   - og:url (the canonical URL - never the tracked/campaign variant)
   - og:image (image URL; recommend 1200x630 for feed previews; state placeholder if not supplied)
   - og:image:alt (accessible alt text for the preview image)
   - og:site_name (the brand's site name)
   - article:published_time (ISO 8601; placeholder if unknown)
   - article:author (author URL if configured, otherwise brand name)

2. TWITTER / X CARD TAGS:
   - twitter:card ("summary_large_image" for blog posts by default)
   - twitter:title (up to 70 chars)
   - twitter:description (up to 200 chars)
   - twitter:image (same as og:image if no dedicated variant)
   - twitter:site (@brand handle; leave as [INSERT @handle] if not supplied)

3. CANONICAL URL: emit `<link rel="canonical" href="[CANONICAL URL]" />`. The canonical URL must be the primary indexable version of the page, stripped of UTM/campaign/tracking parameters. If the page is a syndication of a canonical version elsewhere, point to that original URL instead - never self-canonicalize a syndicated copy.

Output each tag as a ready-to-paste `<meta ... />` / `<link ... />` block.

------------------------------------------------------------
SECTION 3 - AEO (Answer Engine Optimisation)
------------------------------------------------------------

AEO optimises content to appear in featured snippets, People Also Ask boxes, and AI-generated answer panels (Google AI Overview, Bing Copilot, Perplexity, ChatGPT search). The goal is to make content the direct answer to a specific question.

For the same blog post, generate:

1. TARGET QUESTION: The single most likely question a user would type into Google or an AI tool that this blog post should answer.

2. FEATURED SNIPPET ANSWER: A direct, concise answer to that question in 40-60 words. Written to be pulled verbatim by Google or an AI tool. No fluff, no preamble, just the answer.

3. PEOPLE ALSO ASK (PAA) BLOCK: Generate 4 related questions a user might ask after the primary question, each with a 30-40 word direct answer.

4. AI OVERVIEW OPTIMISATION NOTE: One sentence explaining what claim or stat in this content is most likely to be cited by an AI Overview, and why. Must reference a real, sourceable claim - never a fabricated stat.

5. AI ENTITY SIGNALS (GEO): One line listing the brand-entity `sameAs` links this page's schema should carry (Wikipedia, LinkedIn, Crunchbase, Wikidata) so AI systems can bind the citation to the correct brand entity. If the brand does not yet have a Wikipedia/Wikidata entry, flag that as a gap rather than inventing a URL.

------------------------------------------------------------
OUTPUT FORMAT
------------------------------------------------------------

For a single URL, return the following in order:
1. Ready-to-paste `<head>` block with meta title, meta description, all OG tags, all Twitter tags, canonical link
2. AEO block: Target Question | Featured Snippet Answer | PAA Q1-Q4 with answers | AI Overview Note | AI Entity Signals

For a batch (Sr. No. row per URL), fall back to CSV:

Sr. No. | Blog URL | Meta Title | Meta Description | og:title | og:description | og:image | twitter:title | twitter:description | Canonical URL | Target Question | Featured Snippet Answer | PAA Q1 | PAA A1 | PAA Q2 | PAA A2 | PAA Q3 | PAA A3 | PAA Q4 | PAA A4 | AI Overview Note | sameAs URLs

Save to output/Meta/

------------------------------------------------------------
BATCH DEDUP RULE
------------------------------------------------------------

When generating meta for more than one URL in a run, no two rows may share the same meta title verbatim, the same Target Question, or the same Featured Snippet Answer opening sentence. Cross-page duplication in these fields is a self-inflicted cannibalization signal.

------------------------------------------------------------
SELF-CHECK BEFORE OUTPUT
------------------------------------------------------------

- Meta title is under 60 characters and includes the primary keyword?
- Meta description is 140-160 characters and includes a subtle CTA?
- Every OG tag is present (title, description, type, url, image, image:alt, site_name, published_time, author)?
- Twitter card block present (card, title, description, image, site)?
- Canonical URL is stripped of UTM/tracking parameters?
- Featured snippet answer is 40-60 words, direct, and cites nothing that cannot be sourced?
- Every PAA answer is 30-40 words?
- sameAs URLs are real or explicitly flagged as gaps (never fabricated)?
- No em dashes anywhere?

------------------------------------------------------------
FAILURE MODES TO AVOID
------------------------------------------------------------

1. META TITLE = H1 = BLOG TITLE: three identical strings waste the meta-title's separate role as the SERP click hook. The meta title should be optimised for CTR in a SERP snippet; the H1 for on-page reading; they will often differ.

2. OG:URL POINTS TO A CAMPAIGN-TRACKED URL: OG tags with UTM parameters propagate the tracking into every share and pollute analytics. og:url and the canonical must both be the clean primary URL.

3. FEATURED SNIPPET ANSWER RESTATES THE QUESTION BEFORE ANSWERING: "The best way to X is..." wastes the 40-60 word budget. Lead with the answer noun/verb; the question is implied by the surrounding page.

4. FABRICATED sameAs LINKS: if the brand has no Wikipedia entry, no Wikidata Q-id, no Crunchbase profile, mark it as a gap; never invent one. AI systems that cross-check sameAs will drop the entire entity binding on any bad link.

5. CANONICAL POINTS AT SELF ON A SYNDICATED COPY: a Medium/Substack/Dev.to republication must canonical to the original publisher's URL, not to itself, or Google will attribute the original to the republication.

------------------------------------------------------------
RULES
------------------------------------------------------------

- Meta title: under 60 characters, includes primary keyword
- Meta description: 140-160 characters, includes CTA
- OG image: recommend 1200x630 for optimal preview rendering across networks
- Featured snippet answer: 40-60 words, direct and quotable
- PAA answers: 30-40 words each, direct
- No em dashes anywhere
- No passive voice
- Output saved to output/Meta/
